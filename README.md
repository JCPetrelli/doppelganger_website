# Doppelganger Website

A modern, visually striking website for the Berlin-based audiovisual duo Doppelganger.

## Description

This is the official website for Doppelganger, an audiovisual duo comprising Jacopo Castellano and Niels Poensgen. The site features immersive shader-based backgrounds, responsive design, and a minimalist aesthetic that reflects their artistic vision.

## Features

- Full-screen WebGL shader backgrounds using Three.js
- Responsive navigation with mobile hamburger menu
- Embedded YouTube video showcase
- Artist bio sections with external links
- Live dates section
- Contact information
- Custom CNAME for domain configuration

## Structure

```
doppelganger_website/
├── index.html        # Main landing page
├── experiments.html  # Shader experiments page
├── experiments.js    # Shader experiment code
├── script.js         # Main JavaScript with shaders
├── style.css         # Custom styles
├── content.md        # Content source
└── CNAME             # Custom domain configuration
```

## Technologies

- HTML5
- CSS3 with custom styling
- Three.js for WebGL shaders
- JetBrains Mono font from Google Fonts
- Vanilla JavaScript

## Shader Effects

The website features custom GLSL shaders including:
- Chrome liquid effect
- Liquid metal effect

## Usage

Simply open `index.html` in a web browser or deploy to any static hosting service (GitHub Pages, Netlify, etc.).
